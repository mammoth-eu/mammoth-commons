🔬 MAI-BIAS toolkit

A fairness assessment and bias mitigation app. It loads datasets and models, and lets you analyze them through a simple standardized UI. It contains modules from MAMMOth partners and third-party libraries.

🔬 Install now

Choose your needs: fast work on local data, or easy sharing of results via your organization's server?

Make sure you have Python 3.11 in your systems. Most modules also work in later versions too. Use the following boostrapping command to download and run the autostart script mai_bias.sh:

curl -fsSL https://raw.githubusercontent.com/mammoth-eu/mammoth-commons/dev/mai_bias.sh -o mai_bias.sh && chmod +x mai_bias.sh && ./mai_bias.sh

The toolkit's modules install more dependencies on-demand. For some deep learning modules, this may take a while the first time. Troubleshoot common errors or report issues in GitHub.

Open a terminal in an empty directory and use the following curl command to download and run the bootstrap script install.sh. If you are on Windows, manually install docker first and set up the toolkit server in WSL.

curl -fsSL https://raw.githubusercontent.com/mammoth-eu/mammoth-toolkit-releases/dev/install.sh -o install.sh && bash install.sh

You will see more instruction on default credentials and how to stop, restart, or update the toolkit's server when the script completes.

Installation sets up a kubernetes environment may take a while. Docker images are downloaded in the server. Troubleshoot common errors or report issues in GitHub.

🦣 Software

Get direct access to a comprehensive suite of Python libraries and tools across multiple modalities: tabular data, computer vision, graphs / networks, text. These support MAI-BIAS modules.

General-purpose Library

FairBench

A comprehensive AI fairness exploration library with >300 standardized measures. It can evaluate all modalities, including text generation.

General-purpose Library

MMM-fair

A library that supports high-stakes AI decision-making under competing fairness and accuracy demands.

General-purpose ALgorithm

FairBranch

Implementation of FairBranch pipelines for vision and tabular modalities.

Tabular data Algorithm

MBFPP

Implementation of the work Multi-Fairness-under-Class-Imbalance.

Visual data

VB-Mitigator

Implementation and evaluation of existing and new visual bias mitigation methods.

Computer vision Algorithm

FLAC

Implementation of the model for Fairness-Aware Representation Learning by Suppressing Attribute-Class Associations.

Computer vision Dataset

SDFD

The Stable Diffusion Face-image Dataset. It captures broad facial diversity (demographics, biometrics, non-permanent traits).

Graphs / networks Library

NetIn

A library of methods to study network inequalities.

Graphs / networks Algorithm

pygrank-f

Implementation of node ranking debiasing in large graphs.
