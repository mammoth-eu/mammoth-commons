Our toolkit

The MAI-BIAS toolkit is a low-code fairness assessment and bias mitigation app. It brings together software by both our partners and third parties to load datasets and models, and analyze them through a standardized interface.

Install locally or in a server
Assess a dataset in 10 clicks
Share results with non-technical people: examples

Out-of-the-box support for many data types, technology stacks, and fairness concerns. The toolkit adjusts to your setting!

🗄️ Dataset loaders

Load local datasets or automatically use public ones used in fairness literature.

🧮 Model loaders

Import a wide range of trained machine learning models or other data science algorithms.

🔬 Fairness analysis

Metrics, visualizations, and summaries for quantifying and mitigating disparities.

Reuse our software

Apply our bias detection and mitigation code in your projects independently. Software listed here also runs or can be discovered through the MAI-BIAS toolkit.

FairBenchAny dataLibrary

A comprehensive AI fairness exploration library with >300 standardized measures. It can parse any data modality, including generated text.

MMM-fairAny dataLibrary

A library that supports high-stakes AI decision-making under competing fairness and accuracy demands.

FairBranchAny dataAlgorithm

Implementation of FairBranch pipelines for vision and tabular modalities.

MBFPPTabular dataAlgorithm

Implementation of a work on multi-fairness under class imbalance.

VB-MitigatorVisionAlgorithm

Implementation and evaluation of existing and new visual bias mitigation methods.

FaceXVisionAlgorithm

Understanding face attribute classifiers through summary model explanations.

FLACVisionAlgorithm

Implementation of a model for fairness-aware representation learning by suppressing attribute-class associations.

SDFDVisionDataset

A synthetic face image dataset that captures broad facial diversity (demographics, biometrics, non-permanent traits).

NetInNetworksLibrary

A library of methods to study network inequalities.

HyperFairNetworksLibrary

A Python library for generating, evaluating, and improving rankings under fairness constraints.

pygrank-fNetworksAlgorithm

Implementation of node ranking debiasing in large graphs.
