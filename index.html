Our toolkit

The MAI-BIAS toolkit is a fairness assessment and bias mitigation app that brings together software by both our partners and third parties. The toolkit lets you load datasets and models, and analyze them through a simple standardized interface.

Choose your needs: fast work on local data, or easily share results via your organization's server.

Requires Python 3.11 in your systems. Most modules also work in later versions too. Use the following boostrapping command to download and run the autostart script mai_bias.sh in an empty directory:

curl -fsSL https://raw.githubusercontent.com/mammoth-eu/mammoth-commons/dev/mai_bias.sh -o mai_bias.sh && chmod +x mai_bias.sh && ./mai_bias.sh

The toolkit's modules install more dependencies on-demand. For some deep learning modules, this may take a while the first time. Troubleshoot common errors or report issues in the local runner's repository.

Open a terminal in an empty directory and use the following curl command to download and run the bootstrap script install.sh. If you are on Windows, manually install docker first and set up the toolkit server in WSL.

curl -fsSL https://raw.githubusercontent.com/mammoth-eu/mammoth-toolkit-releases/dev/install.sh -o install.sh && bash install.sh

Default credentials and how to stop, restart, or update the server are shown when the server launches. Installation sets up a kubernetes environment may take a while. Docker images are downloaded in the server. Troubleshoot common errors or report issues in the server's repository.

Reuse our software

Apply our bias detection and mitigation code in your projects independently. Software listed here also runs or can be discovered through the MAI-BIAS toolkit.

FairBenchAny dataLibrary

A comprehensive AI fairness exploration library with >300 standardized measures. It can parse any data modality, including generated text.

MMM-fairAny dataLibrary

A library that supports high-stakes AI decision-making under competing fairness and accuracy demands.

FairBranchAny dataAlgorithm

Implementation of FairBranch pipelines for vision and tabular modalities.

MBFPPTabular dataAlgorithm

Implementation of a work on multi-fairness under class imbalance.

VB-MitigatorVisionAlgorithm

Implementation and evaluation of existing and new visual bias mitigation methods.

FaceXVisionAlgorithm

Understanding face attribute classifiers through summary model explanations.

FLACVisionAlgorithm

Implementation of a model for fairness-aware representation learning by suppressing attribute-class associations.

SDFDVisionDataset

A synthetic face image dataset that captures broad facial diversity (demographics, biometrics, non-permanent traits).

NetInNetworksLibrary

A library of methods to study network inequalities.

HyperFairNetworksLibrary

A Python library for generating, evaluating, and improving rankings under fairness constraints.

pygrank-fNetworksAlgorithm

Implementation of node ranking debiasing in large graphs.
